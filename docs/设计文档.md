## 1. 项目概述

### 1.1 项目背景

TodoNote 是 iOS 应用 **Todokit**（清单待办·日记·习惯打卡·番茄钟）的 Android 复刻版本。Todokit 是一款功能集成度高的效率工具，涵盖待办清单、习惯养成、日历规划和番茄专注等核心场景。

### 1.2 项目目标

在 Android 平台上构建一个功能对等、体验优秀的效率管理应用，同时：
- **完全离线运行**：所有数据存储在本地，无需网络连接
- **国内生态适配**：不依赖 Google Play Services / Firebase，可在国内应用商店分发
- **单机优先**：先做单机版，后续再评估云同步需求

### 1.3 核心功能矩阵

| 模块 | 优先级 | 复杂度 | 说明 |
|------|--------|--------|------|
| 待办清单管理 | P1 | ⭐⭐⭐ | 创建/编辑/删除清单，任务CRUD，优先级，进度 |
| 日历视图 | P2 | ⭐⭐⭐ | 日/周/月视图，任务日历映射 |
| 习惯打卡 | P2 | ⭐⭐ | 习惯创建，每日打卡，连续天数统计 |
| 番茄钟 | P3 | ⭐⭐ | 专注/休息计时，状态持久化，前台服务 |
| 数据统计 | P3 | ⭐⭐⭐ | 完成率图表，习惯趋势，成就徽章 |
| 主题个性化 | P3 | ⭐ | 8套配色，深色/浅色模式 |
| 标签分类 | P2 | ⭐ | 标签创建，颜色标记，筛选 |
| 智能提醒 | P2 | ⭐⭐ | 任务到期提醒，习惯打卡提醒 |

## 2. 功能规格

### 2.1 待办清单管理

#### 清单（List）
- 创建清单时自动生成默认标题，支持自定义
- 支持为清单设置颜色标识（8种预设颜色）
- 支持清单描述
- 清单内任务完成进度条显示（如：3/8 已完成）
- 拖拽排序

#### 任务（Task）
- 标题（必填）
- 备注/详细描述（选填）
- 截止日期（选填，支持日期+时间）
- 优先级（高/中/低，或 P1/P2/P3）
- 标签（多选，可创建自定义标签）
- 完成状态切换（带动画反馈）
- 提醒设置（截止前 N 分钟提醒）
- 拖拽排序

### 2.2 日历视图
- 月视图：整月概览，有任务的日期显示小圆点
- 周视图：每周详细日程
- 日视图：当日完整任务列表
- 点击日期查看/快速添加任务

### 2.3 习惯打卡
- 创建习惯（名称、频率、目标次数）
- 每日一键打卡
- 连续打卡天数（Streak）自动统计
- 月度打卡日历（热力图风格）
- 习惯归档（不删除历史记录）

### 2.4 番茄钟
- 默认：25分钟专注 + 5分钟休息
- 每4个番茄钟后15分钟长休息
- 可自定义各阶段时长
- 前台服务保证后台运行
- 完成记录自动保存

### 2.5 数据统计与成就
- 任务完成率（日/周/月）
- 习惯打卡统计
- 番茄钟使用统计
- 成就徽章系统（至少10个可解锁成就）

### 2.6 主题与个性化
- 8套精心设计的配色方案
- 深色/浅色/跟随系统
- Material You 动态取色（Android 12+）
- 标签颜色自定义

## 3. 技术架构

### 3.1 技术选型

| 层次 | 技术 | 说明 |
|------|------|------|
| 语言 | Kotlin 2.0+ | 官方推荐，协程原生支持 |
| UI | Jetpack Compose + Material 3 | 声明式UI，现代Android开发标准 |
| 数据库 | Room (SQLite) | 类型安全，编译时SQL校验，完全离线 |
| DI | Koin | 纯Kotlin DI框架，无Google依赖 |
| 导航 | Navigation Compose | 官方导航组件 |
| 异步 | Kotlin Coroutines + Flow | 响应式数据流 |
| 设置存储 | DataStore Preferences | 替代SharedPreferences |
| 本地化 | Android Localization | strings.xml多语言支持 |

### 3.2 架构模式：MVVM + Clean Architecture

```
┌─────────────────────────────────────────────────┐
│                  UI Layer                        │
│  ┌─────────────┐    ┌──────────────────────┐   │
│  │  Composable │◄──►│    ViewModel         │   │
│  │  Screens    │    │  (StateFlow<UiState>)│   │
│  └─────────────┘    └──────────┬───────────┘   │
├────────────────────────────────┼────────────────┤
│              Domain Layer      │                │
│  ┌─────────────────────────────▼──────────┐    │
│  │          UseCases                      │    │
│  │  (纯Kotlin，无Android依赖，可单元测试)  │    │
│  └─────────────────────────────┬──────────┘    │
│  ┌─────────────────────────────▼──────────┐    │
│  │     Repository 接口 (Interface)         │    │
│  └─────────────────────────────────────────┘    │
├─────────────────────────────────────────────────┤
│              Data Layer                         │
│  ┌─────────────────────────────────────────┐   │
│  │     Repository 实现                      │   │
│  ├─────────────────────────────────────────┤   │
│  │  ┌──────────────┐  ┌────────────────┐  │   │
│  │  │  Room DAO    │  │  DataStore     │  │   │
│  │  └──────┬───────┘  └────────────────┘  │   │
│  │         ▼                               │   │
│  │  ┌──────────────┐                      │   │
│  │  │  SQLite DB   │                      │   │
│  │  └──────────────┘                      │   │
│  └─────────────────────────────────────────┘   │
└─────────────────────────────────────────────────┘
```

### 3.3 数据流

```
User Action → Composable → ViewModel.onEvent(event)
  → UseCase.invoke() → Repository.getData()
  → DAO.query() → SQLite
  → Flow<T> → ViewModel (state update)
  → Composable (recomposition) → UI Update
```

### 3.4 依赖关系（全部本地无网络）

```
┌──────────┐    ┌───────────┐    ┌─────────────┐
│ Compose  │───►│  Koin DI  │───►│   Room DB   │
│ UI Layer │    │  Module   │    │  (SQLite)   │
└──────────┘    └───────────┘    └──────┬──────┘
                                        │
                               ┌────────▼───────┐
                               │   DataStore    │
                               │  (Preferences) │
                               └────────────────┘
```

### 4.2 Room 数据库版本规划

- **Version 1**: 核心表 — List, Task, Tag, TaskTagCrossRef
- **Version 1.1**: 习惯模块 — Habit, HabitCheckIn
- **Version 1.2**: 番茄钟 — PomodoroSession
- **Version 1.3**: 成就系统 — Achievement
- 使用 `AutoMigration` 或手动 migration 策略保证数据不丢失

## 5. UI/UX 设计

### 5.1 导航结构

```
底部导航栏（5个Tab）
├── 📋 任务 (Tasks) — 默认首页
│   └── 任务详情 (TaskDetail)
├── 📅 日历 (Calendar)
├── 🔄 习惯 (Habits)
│   └── 习惯详情 (HabitDetail)
├── ⏱ 番茄钟 (Timer)
└── ⚙️ 设置 (Settings)
    ├── 主题选择 (ThemeSelector)
    ├── 数据备份/恢复 (BackupRestore)
    └── 关于 (About)
```

### 5.2 配色方案

预设8套主题色（灵感来源于 Todokit）：

| 主题名 | 主色 | 适用场景 |
|--------|------|----------|
| 默认蓝 | #2196F3 | 专业、清爽 |
| 海洋 | #00BCD4 | 平静、专注 |

### 5.3 交互规范

- **新建任务**：底部弹出 BottomSheet
- **完成任务**：点击 Checkbox，带动画和触感反馈
- **删除**：左滑显示"删除"，带撤销 Snackbar
- **排序**：长按拖拽
- **日历操作**：点击日期查看详情，长按快速添加
- **搜索**：顶部搜索栏，实时过滤

### 5.4 支持的本地化

- 简体中文（默认）
- 英文（可选）
- 日期格式：2026年5月26日 / 2026-05-26
- 时间格式：24小时制（默认）/ 12小时制

## 7. 国内环境适配

### 7.1 避免的依赖

| 服务/库 | 原因 | 替代方案 |
|---------|------|----------|
| Google Play Services | 国内不可用 | 完全不使用 |
| Firebase (FCM) | 国内不可用 | AlarmManager + NotificationManager |
| Firebase Auth | 国内不可用 | 单机版无需用户系统 |
| Firebase Analytics | 国内不可用 | 不使用分析服务 |
| Firebase Crashlytics | 国内不可用 | 本地日志 + 可选的bugly集成 |
| Google Maps | 国内不可用 | 不使用地图功能 |

### 7.2 应用商店分发

支持的国内应用商店：
- 华为应用市场
- 小米应用商店
- OPPO应用商店
- vivo应用商店
- 应用宝（腾讯）
- 百度手机助手
- 酷安

### 7.3 合规要求

- 遵循《个人信息保护法》（PIPL）
- 由于完全不收集数据，隐私政策相对简单
- 在应用内声明"本应用无需网络权限，所有数据仅存储于本地"
- 适配 Android 各厂商的推送通道（如需通知功能）

### 7.4 构建配置要点

```kotlin
// AndroidManifest.xml — 无网络权限
<uses-permission android:name="android.permission.POST_NOTIFICATIONS" />
<uses-permission android:name="android.permission.USE_EXACT_ALARM" />
<uses-permission android:name="android.permission.FOREGROUND_SERVICE" />
<uses-permission android:name="android.permission.FOREGROUND_SERVICE_SPECIAL_USE" />
<!-- 注意：没有 INTERNET 权限 -->
```
